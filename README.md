# Mental Health Journal Analyzer

## Overview
A web application that helps users write daily journal entries and analyze emotions using AI.

## Features
- Write daily journal entries
- Emotion and mood analysis
- Clean and responsive UI
- User-friendly dashboard

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS

## How to Run
1. Clone the repository
2. Install dependencies:
   npm install
3. Start project:
   npm start
